## このときの検証結果

- 文字サイズ200%での破綻 — 失敗 → 修正済み。等倍では崩れず200%でのみ発生することを、
  390pxの実レイアウトで撮り比べて確認。ヘッダーのサイト名がハンバーガーと重なりメニューを開けない、
  アクセス情報の住所末尾・メールアドレスが欠落、下部固定バーが本文26px分を覆う。
- 横方向のオーバーフロー — 失敗 → 修正済み。全幅で `scrollWidth = clientWidth + 180`。
  原因は `.hero::after`（`right: -180px`）。`body { overflow-x: hidden }` が症状を隠していた。
- コントラスト比 — 一部失敗 → 修正済み。本文約90組はすべて4.5:1以上で問題なし。
  一方でフォーカスリング（対濃緑 1.39:1 / 1.00:1）と入力欄の枠線（1.25:1）が基準3:1を下回っていた。
- 静的チェック、表記揺れ、修正後の再検証、本番反映後の確認、挿絵差し替え後の検証、
  事実反映後の本番確認 — いずれも成功。
